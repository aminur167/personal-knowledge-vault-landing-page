# Personal Knowledge Vault - Landing Page

A clean, modern, and fully responsive landing page designed for a Personal Knowledge Management (PKM) application. Built to practice pixel-perfect UI translation, responsive typography, and structured CSS architecture.

## Highlights

- **Hero Banner**: Engaging headline, value proposition statement, and primary CTA.
- **Feature Showcase**: Grid layout highlighting markdown editing, graph visualization, and offline-first storage.
- **Visual Design**: Sleek dark/light aesthetic inspired by modern productivity tools (Notion, Obsidian).
- **Responsive Layout**: Fluid breakpoints adapting smoothly across mobile, tablet, and desktop screens.

## Tech Stack

- **HTML5**: Semantic markup (`<header>`, `<main>`, `<section>`, `<footer>`)
- **CSS3**: Flexbox, CSS Grid, custom properties (CSS variables), media queries
- **Figma**: Reference UI design (`KnowledgeVault.fig` included in repository)

## Local Preview

Open `index.html` in your browser or run with VS Code Live Server.
